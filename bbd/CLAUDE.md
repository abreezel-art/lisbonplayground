## Pedro Second Brain

The project also includes a structured knowledge base created from workshop transcripts.

Expected location:

`knowledge/pedro-second-brain/`

If the folder has a different name, locate the directory containing thematic files or folders such as:

- `Core Philosophy`
- `State of Play`
- `Presence`
- `Authenticity`
- `Connection`
- `Mistakes`
- `Emotional Work`
- `How Pedro Teaches`
- `Mental Models`
- `Copywriting Nuggets`
- quote or concept indexes
- source transcripts

Use this knowledge base whenever you analyse or write website copy related to Pedro, Being Before Doing, clowning, play, emotions, mistakes, connection, presence, authenticity, or his teaching method.

Do not treat the knowledge base as permission to rewrite approved copy. Approved decisions in `copy-status.md` still take precedence.

## Source hierarchy

Use the following hierarchy:

1. **Approved decisions and protected copy** in `copy-status.md`.
2. **Page strategy and section purpose** in `creative-brief.md`.
3. **Pedro’s original writing** in `pedro-texts.md`.
4. **Verified transcript passages** in the knowledge base source files.
5. **Structured Second Brain material** for concept discovery, vocabulary, mental models, metaphors, and copy directions.
6. **Editorial bridge copy** written in a voice compatible with Pedro.

When sources conflict, do not silently choose. Explain the conflict and ask before changing approved or strategically important copy.

## Core rule

Before changing website copy:

1. Read the relevant project documentation.
2. Check `copy-status.md` for approved decisions.
3. Search Pedro Second Brain for relevant concepts, quotes, mental models and teaching principles.
4. Verify direct Pedro quotes against source files.
5. Do not attribute participant speech to Pedro.
6. Do not modify approved sections without explicit approval.
7. Work section by section.

Before inventing wording, search Pedro’s existing language first.

Use Pedro’s actual concepts, distinctions, metaphors, teaching logic, and vocabulary as the primary creative material. Write coherent website copy from that material rather than assembling a wall of quotations.
